# Phase 1 — Data Model: Standing content series

**Feature**: `071-evergreen-series` | **Spec**: [spec.md](./spec.md) | **Research**: [research.md](./research.md)

Three new tables, seven new enums, three widened enums (`generation_mode`, `llm_usage_purpose`,
`membership_action`), one new column on `posts`, two new columns on `generation_failures` — all in **one** forward-only SQL
migration generated by `pnpm db:generate` and committed, with `pnpm db:check` green (FR-001).

No backfill: every existing row is unaffected, and every new column on an existing table is nullable
or has a default.

---

## 1. `standing_series` — the configuration (W2, W3, FR-001)

Project-owned. Holds what to generate and how often, and nothing about any particular post.

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` pk | `gen_random_uuid()` |
| `project_id` | `uuid` not null | → `projects.id` **cascade** |
| `name` | `text` not null | 1–100 after trimming (FR-002) |
| `brief` | `text` not null | 1–`BRIEF_MAX` (2000) — what the series is about (W5, FR-004) |
| `template` | `text` not null | 1–`INSTRUCTIONS_MAX` (2000) — how to write (W4, FR-004) |
| `template_fields` | `text[]` not null | always `{}` in this entry; the column exists for `dated-series` (W3, **S29**) |
| `voice_profile_id` | `uuid` not null | **one** column, not a pinned version: the current version is taken at run time (W18, FR-020) |
| `target_account_ids` | `uuid[]` not null | 1–50 (FR-006) |
| `cadence_count` | `smallint` not null | 1–10 (W8, FR-005) |
| `cadence_period` | `standing_series_period` not null | `day` \| `week` \| `month` (W7) |
| `media_source` | `standing_series_media_source` not null | `none` \| `pool` \| `generate` (W25, FR-034) |
| `media_pool_tag` | `text` null | only with `pool`; 1–`TAG_MAX_LENGTH` (40), validated by the existing `tagSchema` |
| `image_prompt` | `text` null | required with `generate`; 1–`IMAGE_PROMPT_MAX` (1000) (W27, FR-037) |
| `requested_approval` | `approval_policy` null | what was asked for, as `generation_jobs` records it |
| `requested_scheduling` | `scheduling_policy` null | — |
| `approval_policy` | `approval_policy` not null | resolved and authorised at create/edit (W21, FR-027) |
| `scheduling_policy` | `scheduling_policy` not null | only two values exist, so FR-033 holds by construction |
| `enabled` | `boolean` not null | default `true` |
| `auto_paused_reason` | `standing_series_pause_reason` null | `no_output` today (W34, FR-053); null when a person paused it |
| `last_run_at` | `timestamptz` null | set when a run **opens** |
| `next_run_at` | `timestamptz` not null | always a period boundary (W9, FR-009) |
| `lease_owner` | `uuid` null | the claim's token (**S6**) |
| `lease_until` | `timestamptz` null | — |
| `last_claimed_at` | `timestamptz` null | rotation (W32, FR-046) |
| `created_by_user_id` | `uuid` null | → `user.id` set null |
| `created_at` / `updated_at` | `timestamptz` not null | `$onUpdate` on the latter |

**Constraints**

- `unique("standing_series_project_id_uq") (project_id, id)` — the composite-FK anchor every
  project-owned table here has.
- `uniqueIndex("standing_series_project_name_uq") (project_id, lower(name))` — FR-002, case-insensitive.
- `foreignKey (project_id, voice_profile_id) → voiceProfiles(project_id, id)` — no `onDelete`, i.e.
  `NO ACTION`, exactly as `generation_jobs_voice_profile_fk`. Safe because voice profiles are
  archived, never deleted (**S20**).
- `check name_len`: `char_length(name) BETWEEN 1 AND 100 AND btrim(name) = name`
- `check brief_len`: `char_length(brief) BETWEEN 1 AND 2000`
- `check template_len`: `char_length(template) BETWEEN 1 AND 2000`
- `check targets_card`: `cardinality(target_account_ids) BETWEEN 1 AND 50`
- `check cadence_count_range`: `cadence_count BETWEEN 1 AND 10`
- `check pool_tag_only_for_pool`: `media_pool_tag IS NULL OR media_source = 'pool'`
- `check image_prompt_pair`: `(media_source = 'generate') = (image_prompt IS NOT NULL)`
- `check image_prompt_len`: `image_prompt IS NULL OR char_length(image_prompt) BETWEEN 1 AND 1000`
- `check lease_pair`: `(lease_until IS NULL) = (lease_owner IS NULL)`
- `check auto_pause_implies_disabled`: `auto_paused_reason IS NULL OR enabled = false`
- `index claim_idx` on `(next_run_at, last_claimed_at NULLS FIRST, id) WHERE enabled`
- `index project_name_idx` on `(project_id, lower(name))` — the list's order

**Deliberately absent**: no `posting_instructions_snapshot` (**S28**), no pinned voice version
(W18), no per-series provider/model/credential/rate-limit/spend cap (spec out of scope), no
`open_run_id` (the claim's `EXISTS` answers it), no stored counters.

## 2. `standing_series_runs` — one period's work (W2, FR-015)

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` pk | |
| `project_id` | `uuid` not null | → `projects.id` cascade |
| `series_id` | `uuid` not null | composite FK → `standing_series`, **cascade** |
| `period` | `standing_series_period` not null | the cadence period at open (**S4**) |
| `period_start` | `date` not null | the **local** date the period starts (**S4**) |
| `period_start_at` | `timestamptz` not null | the resolved instant, for display and ordering |
| `requested_count` | `smallint` not null | 1–10: how many posts it was asked for |
| `config` | `jsonb` not null | the configuration snapshot (**S2**) — see § 6 |
| `plan` | `jsonb` null | `{ angles: [{ title, description }] }`; null until planned, and null forever for a one-post run (W15, FR-016) |
| `plan_attempt_count` | `smallint` not null | default 0 (**S9**) |
| `plan_next_attempt_at` | `timestamptz` null | backoff for the plan call (**S9**) |
| `missed_periods` | `smallint` not null | default 0 — boundaries that passed with no run (W10, FR-013) |
| `dropped_account_ids` | `uuid[]` not null | default `{}` (**S21**) |
| `blocked_reason` | `standing_series_block_reason` null | `voice_profile_missing` \| `no_usable_target` (**S20**) |
| `outcome` | `standing_series_outcome` null | written once, at close (**S3**) |
| `opened_at` | `timestamptz` not null | default now |
| `closed_at` | `timestamptz` null | — |

**Constraints**

- `unique("standing_series_runs_project_id_uq") (project_id, id)`
- `unique("standing_series_runs_period_uq") (series_id, period, period_start)` — FR-012, at most one
  run per series per period, enforced by the database rather than by timing (**S4**).
- `uniqueIndex("standing_series_runs_open_uq") (series_id) WHERE closed_at IS NULL` — FR-014, at most
  one open run per series.
- `foreignKey (project_id, series_id) → standing_series(project_id, id) ON DELETE CASCADE` — FR-057.
- `check requested_count_range`: `requested_count BETWEEN 1 AND 10`
- `check closed_pair`: `(closed_at IS NULL) = (outcome IS NULL)`
- `check single_post_has_no_plan`: `requested_count > 1 OR plan IS NULL`
- `check missed_nonneg` / `check plan_attempts_nonneg`
- `index series_recent_idx` on `(project_id, series_id, opened_at DESC)` — the run history page
- `index closed_idx` on `(closed_at)` `WHERE closed_at IS NOT NULL` — self-pause (**S35**) and
  housekeeping (**S39**)

## 3. `standing_series_positions` — one intended post (FR-021, FR-038, FR-039)

| Column | Type | Notes |
|---|---|---|
| `id` | `uuid` pk | |
| `project_id` | `uuid` not null | → `projects.id` cascade |
| `run_id` | `uuid` not null | composite FK → runs, **cascade** |
| `position` | `smallint` not null | 0-based, `< requested_count` |
| `status` | `standing_series_position_status` not null | `queued` \| `running` \| `produced` \| `failed` \| `skipped`, default `queued` |
| `media_asset_id` | `uuid` null | → `media_assets.id` **restrict** (as `generation_job_items` does) |
| `attempt_count` | `smallint` not null | default 0 |
| `next_attempt_at` | `timestamptz` not null | default now |
| `pending_retry` | `jsonb` null | the shared `PendingRetry` shape from `generation/core.ts` |
| `last_error_kind` | `generation_job_item_error` null | the **existing** enum (**S18**) |
| `last_error` | `text` null | ≤ 500, always a fixed message from `llmFailureMessage` |
| `skip_reason` | `standing_series_skip_reason` null | (**S19**) |
| `skip_account_id` | `uuid` null | the account whose media requirement failed (FR-038) |
| `started_at` / `finished_at` | `timestamptz` null | |
| `created_at` / `updated_at` | `timestamptz` not null | |

**Constraints**

- `unique("standing_series_positions_project_id_uq") (project_id, id)`
- `unique("standing_series_positions_run_position_uq") (run_id, position)` — the (run, position)
  identity FR-021 rests on.
- `foreignKey (project_id, run_id) → standing_series_runs(project_id, id) ON DELETE CASCADE`
- `uniqueIndex("standing_series_positions_active_media_uq") (project_id, media_asset_id)
  WHERE media_asset_id IS NOT NULL AND status IN ('queued','running')` — the pool reservation
  (**S15**). `failed` is **not** in the predicate: a lasting failure is never retried, so its image
  returns to the pool.
- `check position_nonneg`: `position >= 0`
- `check last_error_len`: `last_error IS NULL OR char_length(last_error) <= 500`
- `check skip_pair`: `(status = 'skipped') = (skip_reason IS NOT NULL)`
- `check skip_account_needs_reason`: `skip_account_id IS NULL OR skip_reason IS NOT NULL`
- `check failed_has_kind`: `status <> 'failed' OR last_error_kind IS NOT NULL`
- `check pending_retry_state`: `pending_retry IS NULL OR status IN ('queued','running')`
- `index due_idx` on `(run_id, position) WHERE status = 'queued'`
- `index counts_idx` on `(project_id, run_id, status)`

## 5. Changes to existing tables

**`posts`** — one new column (**S10**):

- `standing_series_position_id uuid` null
- `foreignKey (project_id, standing_series_position_id) → standing_series_positions(project_id, id)
  ON DELETE SET NULL` — a deleted series leaves every post it produced in the project (FR-057)
- `uniqueIndex("posts_standing_series_position_uq") (standing_series_position_id)
  WHERE standing_series_position_id IS NOT NULL AND deleted_at IS NULL` — FR-021's uniqueness, the
  mirror of `posts_generation_job_item_uq`
- the existing `posts_series_pair` CHECK is untouched; this column is independent of it

**`generation_failures`** — two new columns (**S12**):

- `standing_series_run_id uuid` null, `foreignKey (project_id, standing_series_run_id) →
  standing_series_runs(project_id, id) ON DELETE CASCADE`
- `standing_series_position smallint` null — null for a **plan** failure
- `check standing_mode_pair`:
  `(mode IN ('standing_series_plan','standing_series_post')) = (standing_series_run_id IS NOT NULL)`
- `check standing_position_needs_run`:
  `standing_series_position IS NULL OR standing_series_run_id IS NOT NULL`
- `index project_run_idx` on `(project_id, standing_series_run_id)
  WHERE standing_series_run_id IS NOT NULL`

**Widened enums**

- `generation_mode` += `standing_series_plan`, `standing_series_post`
- `llm_usage_purpose` += `generate.standing_series_plan`, `generate.standing_series_post` (**S13**)
- `membership_action` += `standing_series_create`, `standing_series_update`, `standing_series_pause`,
  `standing_series_resume`, `standing_series_delete` (**S27**)

`ALTER TYPE … ADD VALUE` adds each value without using it in the same transaction, which is what
Postgres requires and what the existing migrations already do.

**`src/server/db/project-owned.ts`** gains three lines — `standing_series`,
`standing_series_runs`, `standing_series_positions`, each `project_id` — which is what makes
`tests/integration/scope-check.test.ts` cover them (FR-065).

## 6. In-memory shapes

### `StandingSeriesRunConfig` (`src/lib/validation/standing-series.ts`)

The run snapshot (**S2**), parsed on every read:

```text
{ v: 1,
  brief, template, templateFields: string[],
  voiceProfileId,
  targetAccountIds: string[],
  cadence: { count, period },
  media: { source: "none" } | { source: "pool", tag: string | null }
       | { source: "generate", prompt: string },
  requested: { approval: ApprovalPolicy | null, scheduling: SchedulingPolicy | null },
  resolved:  { approval: ApprovalPolicy,        scheduling: SchedulingPolicy } }
```

Invariant: the producer reads **only** this, never the series row — which is what makes FR-056 true
with no lock between a person's edit and the worker.

### `StandingSeriesPlan`

`{ angles: { title, description }[] }` — the same shape `generation_series.plan` stores, so
`seriesPlanStored` and `angleInput` are reused rather than redefined (FR-016).

### `ClaimedStandingSeries` (`src/server/dal/standing-series-claims.ts`)

```text
{ series: StandingSeriesRecord,   // after the claim patch
  token: string,                  // the lease_owner this claim wrote
  owner: string,                  // the credential owner, from credentialOwnerFor
  probe: boolean,                 // the one series a held owner was allowed through
  recovered: boolean }            // the lease had expired
```

### `StandingSeriesCounts` (`src/server/scheduler/standing-series.ts`)

`claimed, recovered, runsOpened, runsClosed, produced, skipped, failed, retried, deferred, released,
finishing, blocked, autoPaused, requeued, staleResults, notConfigured, notRunnable, held, probed` —
reported in the tick summary and the `standing_series` heartbeat (FR-047).

### `StandingSeriesView` / `StandingSeriesRunView` (`src/server/services/standing-series/read.ts`)

What the screens render: the series' fields, its state (`running` | `paused` |
`paused_by_product` with the reason), its resolved policies, its targets as account names and
provider keys, `lastRunAt`, `nextRunAt`, the credit hold (reusing `generationCreditHold`), and per
run its period, counts derived from positions, outcome, the produced posts' ids, and each skip and
failure with its reason and message.

## 7. Lifecycle

| Event | Writes |
|---|---|
| **Create** | one `standing_series` row; `next_run_at = nextBoundaryAfter(now)`; one audit row |
| **Edit** | the series row only; an open run is untouched (**S2**, FR-056); one audit row |
| **Pause** | `enabled = false`, `auto_paused_reason = null`; one audit row. The open run stays open |
| **Resume** | `enabled = true`, `auto_paused_reason = null`, `next_run_at = nextBoundaryAfter(now)`; one audit row (FR-055) |
| **Delete** | the series row; runs, positions and their failures cascade; every post's `standing_series_position_id` becomes null and the post is otherwise untouched (FR-057); one audit row |
| **Claim** | `lease_owner`, `lease_until`, `last_claimed_at`; `attempt_count + 1` on a recovered `running` position (never for a probe) |
| **Open a run** | close a stale open run as `incomplete`; insert the run with its `config`, `period`, `period_start`, `requested_count`, `missed_periods`, `dropped_account_ids`; insert `requested_count` positions; set the series' `last_run_at = now` and `next_run_at = nextBoundaryAfter(period_start_at)` |
| **Plan** | `UPDATE runs SET plan = … WHERE id = … AND plan IS NULL` |
| **Reserve / generate media** | `UPDATE positions SET media_asset_id = … WHERE id = … AND media_asset_id IS NULL` |
| **Produce a post** | one transaction: `saveGeneratedPost` with `{ standingSeriesPositionId }` + position stays `running`. Then variants and `applyApprovalPolicy` outside it, then `status = 'produced'`, `finished_at` |
| **Skip** | `status = 'skipped'`, `skip_reason`, `skip_account_id`, `finished_at`; no attempt, no failure (FR-039) |
| **Fail** | `status = 'failed'`, `last_error_kind`, `last_error`, `finished_at`; one `generation_failures` row |
| **Retry** | `status = 'queued'`, `attempt_count + 1`, `next_attempt_at = nextRetryAt(...)` |
| **Billing refusal** | `status = 'queued'`, `next_attempt_at = now`, **no** attempt counted, hold set by the shared wrapper (FR-051) |
| **Close a run** | `outcome` from `deriveRunOutcome(counts)`, `closed_at`; then the self-pause check (**S35**) |
| **Housekeeping** | closed runs older than 90 days, 200 per tick; positions and failures cascade (**S39**) |

## 8. What the data model deliberately does not gain

- No date-pegged occurrence table — `dated-series` adds one, and **nothing** in §§ 2–3 has to change
  to accommodate it: a second occurrence rule writes a run and its positions and stops there
  (SC-012).
- No per-post override, no editable plan, no re-run of a closed run.
- No stored counters, no denormalised "posts produced" on the series.
- No column on `llm_call_usage` (**S13**), no webhook event, no notification row (**S40**).
- No video: `media_asset_id` is only ever set to an asset whose `kind` is `image`, enforced by the
  pool query and by `imagesForModel` refusing anything else.
